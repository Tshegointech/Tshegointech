## ⚡ About

I am a final-year BSc Computer Science and Mathematics student at Sol Plaatje University in Kimberley, South Africa. My work sits at the intersection of **rigorous statistical theory**, **production ML engineering**, and **real African fintech context**.

I do not build toy models on clean datasets. I build systems that understand how SIM swap fraud cascades through USSD channels, how concept drift collapses a classifier during a load-shedding-driven fraud spike, and how PayShap's instant settlement window creates a sub-second exploit window for mule networks.

<br/>

> A structured, production-grade ML portfolio targeting real South African banking fraud patterns across escalating complexity. Every project uses a fixed pipeline: **PostgreSQL 16** (raw data + feature store) → **R** (statistical analysis) → **Python/Jupyter** (EDA, ML, feature engineering) → **Power BI** (dashboarding). SA-specific signals are present throughout: SIM swap events, USSD channel, SASSA recipients, stokvel patterns, SADC cross-border IPs, and load-shedding-correlated fraud windows.
